# Technology Stack

**Analysis Date:** 2026-02-20

## Languages

**Primary:**
- C11 (ISO/IEC 9899:2011) - Bitcoin protocol implementation, consensus engine, networking, storage

**Secondary:**
- Python 3 - Regtest mining utility (`scripts/regtest_miner.py`), network testing tools

## Runtime

**Environment:**
- POSIX-compliant operating systems (Linux, macOS, BSD)
- Windows (via `src/platform/win32.c` implementation, not currently active)
- No runtime dependencies beyond standard C library and OS sockets/threading

**Compilation:**
- C11 compiler (GCC, Clang, or MSVC)
- `cc` command (defaults to system C compiler)

**Package Manager:**
- None - no external dependencies. All required functionality is either standard C library or vendored.

## Frameworks

**Core:**
- None - pure C implementation with no framework dependencies

**Networking:**
- Platform abstraction layer (`src/platform/posix.c`) providing TCP socket operations
  - Low-level socket API (create, connect, bind, listen, send, recv)
  - Blocking I/O with support for async connections
  - DNS resolution via `getaddrinfo()`
  - Threading via POSIX pthreads

**Testing:**
- Custom unit test framework (`test/unit/test_utils.h/c`)
  - Assertion macros (assert_equals, assert_true, assert_false)
  - Test suite runner (`test/run_all_tests.sh`)
  - No external test framework (Gtest, Check, etc.)

**Build/Dev:**
- GNU Make (`Makefile`) - Compiles main binary and 40+ unit test executables
- clangd LSP (``.clangd`) - IDE integration with strict C11 checking
- AddressSanitizer & LeakSanitizer - Memory safety validation in CI/CD

## Key Dependencies

**Embedded (Vendored):**
- **libsecp256k1** (`lib/secp256k1/`) - Elliptic curve cryptography
  - Version: Bitcoin Core integration
  - Compiled with: `ENABLE_MODULE_EXTRAKEYS`, `ENABLE_MODULE_SCHNORRSIG`
  - Purpose: ECDSA signatures, Schnorr signatures (BIP-340), key operations
  - Integration: `src/crypto/secp256k1.c` wraps with Bitcoin-specific APIs
  - Files: `lib/secp256k1/src/secp256k1.c`, precomputed tables, contrib/lax_der_parsing.c

- **SQLite** (`lib/sqlite/sqlite3.c/h`) - Embedded relational database
  - Version: 3.x amalgamation
  - Purpose: Persistent storage of UTXO set (chainstate) and block index
  - Mode: WAL (Write-Ahead Logging) for concurrency and crash safety
  - Configuration: `synchronous=NORMAL`, `foreign_keys=ON`
  - Files: Compiled as single `lib/sqlite/sqlite3.o`
  - Interface: `src/storage/db.c` provides thin transaction wrapper

**Standard C Library:**
- `stdio.h` - I/O and logging
- `stdlib.h` - Memory allocation
- `string.h` - String/memory operations
- `stdint.h` - Fixed-size integer types
- `stdbool.h` - Boolean type
- `pthread.h` - POSIX multithreading
- `math.h` - Floating-point calculations (difficulty conversion)

**System Libraries:**
- `libm` (math library) - Linked via `-lm` for difficulty calculations
- `libpthread` (threading library) - Linked via `-pthread` for concurrent peer handling

## Configuration

**Environment:**
- Compile-time network selection via `-D` flags:
  - `-DECHO_NETWORK_MAINNET` (default) - Bitcoin mainnet
  - `-DECHO_NETWORK_TESTNET` - Bitcoin testnet3
  - `-DECHO_NETWORK_REGTEST` - Regression test network
- Compile-time consensus rules frozen in `include/echo_config.h`
- Platform configuration in `include/echo_platform_config.h`

**Build:**
- `Makefile` - Main build configuration
- `.clangd` - clangd LSP server configuration for strict C11 checking
- `compile_commands.json` - Generated by `generate_compile_commands.sh` for IDE integration
- No `.env` or runtime config files - all compile-time

**Cryptographic Configuration:**
- Soft fork activation heights hardcoded per network:
  - P2SH (BIP-16), BIP-34, CLTV (BIP-65), CSV (BIP-68), SegWit (BIP-141), Taproot (BIP-340)
  - Mainnet, Testnet3, and Regtest heights differ

## Platform Requirements

**Development:**
- C11 compiler (clang-15+ or GCC 9+)
- Make (GNU or BSD)
- Git (for submodule integration)
- Python 3 (optional, for regtest_miner.py)
- clang-tools-extra (optional, for clang-tidy linting)

**Build Flags:**
```bash
# Mainnet (default)
make

# Testnet (with network flag)
make CFLAGS="-std=c11 ... -DECHO_NETWORK_TESTNET"

# Regtest
make CFLAGS="-std=c11 ... -DECHO_NETWORK_REGTEST"

# Memory safety checks (CI/CD)
make CFLAGS="-std=c11 ... -fsanitize=address -fno-omit-frame-pointer"
```

**Production:**
- Deployment target: Bitcoin mainnet, testnet3, or regtest (compile-time selection)
- No external service dependencies
- Local filesystem for block storage and chainstate
- Local TCP ports for P2P (8333/mainnet, 18333/testnet, 18444/regtest) and RPC (8332/mainnet)

**Resource Constraints:**
- Block storage: `~400 GB` for mainnet full archival node
- UTXO database: `~10-15 GB` SQLite database in chainstate directory
- Memory: Configured peer limits: 64 outbound + 100 inbound = 164 max connections
- Disk: Pruning support with 550 MB minimum retention for reorg safety
