The current `peer_send_message_internal` in `peer.c` has no `MSG_BLOCK` case in its switch statement and uses a fixed 20KB stack buffer (`payload_buf[20480]`). Blocks can be up to 4MB. Add MSG_BLOCK support with dynamic allocation.

**Add a new case before the `default:` in `peer_send_message_internal`:**

```c
case MSG_BLOCK: {
  /* Blocks can be up to 4MB — too large for the 20KB stack buffer.
   * Compute exact size, allocate on heap, serialize, send, free. */
  size_t block_size = block_serialize_size(&msg->payload.block.block);
  if (block_size == 0) {
    return ECHO_ERR_INVALID_PARAM;
  }

  uint8_t *block_buf = malloc(block_size);
  if (!block_buf) {
    return ECHO_ERR_MEMORY;
  }

  size_t block_written = 0;
  result = msg_block_serialize(&msg->payload.block, block_buf,
                               block_size, &block_written);
  if (result != ECHO_SUCCESS) {
    free(block_buf);
    return result;
  }

  /* Build and send header */
  msg_header_t block_header;
  block_header.magic = MAGIC_MAINNET;
  memset(block_header.command, 0, COMMAND_LEN);
  const char *block_cmd = msg_command_string(MSG_BLOCK);
  if (block_cmd) {
    memcpy(block_header.command, block_cmd, strlen(block_cmd));
  }
  block_header.length = (uint32_t)block_written;
  block_header.checksum = msg_checksum(block_buf, block_written);

  uint8_t block_hdr_buf[24];
  result = msg_header_serialize(&block_header, block_hdr_buf, sizeof(block_hdr_buf));
  if (result != ECHO_SUCCESS) {
    free(block_buf);
    return result;
  }

  int sent = plat_socket_send(peer->socket, block_hdr_buf, 24);
  if (sent <= 0) {
    free(block_buf);
    return ECHO_ERR_SOCKET;
  }

  /* Send payload — may need multiple sends for large blocks */
  size_t total_sent = 0;
  while (total_sent < block_written) {
    sent = plat_socket_send(peer->socket, block_buf + total_sent,
                            block_written - total_sent);
    if (sent <= 0) {
      free(block_buf);
      return ECHO_ERR_SOCKET;
    }
    total_sent += (size_t)sent;
  }

  free(block_buf);
  peer->last_send = plat_time_ms();
  return ECHO_SUCCESS;  /* Early return — skip the shared send path below */
}
```

**Important:** This case does an early return (sends header + payload itself) rather than falling through to the shared `payload_buf` send path below the switch. This is because the block payload lives on the heap and must be freed after send, which doesn't fit the shared path's stack buffer pattern.

**Also add a MSG_BLOCK case to `peer_queue_message`'s deep-copy switch.** Currently the switch only deep-copies `MSG_INV`, `MSG_GETDATA`, `MSG_NOTFOUND` (inventory pointer). For `MSG_BLOCK`, the `block_t` inside `msg_block_t` contains owned pointers (`txs` array, and within each tx: `inputs`, `outputs`, witnesses). The shallow copy done by `entry->message = *msg` will create dangling pointers if the caller frees the original block.

Add after the existing `MSG_NOTFOUND` case in `peer_queue_message`:

```c
case MSG_BLOCK: {
  /* block_t contains owned pointers (txs, inputs, outputs, witnesses).
   * The caller passes a parsed block that it will block_free() after queueing.
   * We must deep-copy the block data to avoid use-after-free.
   *
   * Strategy: serialize the block into a heap buffer now, store it as raw
   * bytes in a new field, and send from that buffer. This avoids needing
   * a full block_t deep-copy which would require cloning every tx/input/output.
   *
   * HOWEVER — the existing architecture sends from msg_t, not raw bytes.
   * The simplest correct approach: mark allocated=true and have the caller
   * NOT free the block_t — transfer ownership to the queue entry.
   * Document this ownership transfer clearly.
   */
  entry->allocated = ECHO_TRUE;
  /* Ownership transferred: caller must NOT call block_free after queueing.
   * The send-queue flush path will free via block_free when entry is consumed. */
  break;
}
```

**Then update the queue entry cleanup** (find where `allocated` entries are freed after send). Search for where `entry->allocated` is checked and `free()` is called — add a `MSG_BLOCK` case there that calls `block_free(&entry->message.payload.block.block)`.

Look for the send-queue flush function (likely `peer_flush_send_queue` or inside `peer_send_queued`). Add:

```c
if (entry->allocated) {
  switch (entry->message.type) {
  case MSG_INV:
  case MSG_GETDATA:
  case MSG_NOTFOUND:
    free(entry->message.payload.inv.inventory);
    break;
  case MSG_BLOCK:
    block_free(&entry->message.payload.block.block);
    break;
  default:
    break;
  }
}
```

**The complete handler for `if (inv->type == INV_BLOCK || inv->type == INV_WITNESS_BLOCK)` should be:**

```c
if (inv->type == INV_BLOCK || inv->type == INV_WITNESS_BLOCK) {
  bool want_witness = (inv->type == INV_WITNESS_BLOCK);

  /*
   * Block serving: look up block in index, check availability, serve.
   * Three notfound cases: (1) unknown hash, (2) pruned, (3) header-only (not downloaded yet).
   */

  /* Step 1: Check if block exists in our index */
  block_index_entry_t entry;
  echo_result_t blk_result = ECHO_ERR_NOT_FOUND;
  if (node->block_index_db_open) {
    blk_result = block_index_db_lookup_by_hash(
        &node->block_index_db, &inv->hash, &entry);
  }

  if (blk_result == ECHO_ERR_NOT_FOUND) {
    /* Unknown block — not in our index at all */
    log_debug(LOG_COMP_NET, "Requested block not in index, sending notfound to %s",
              peer->address);
    goto serve_block_notfound;
  }
  if (blk_result != ECHO_OK) {
    /* Database error — skip silently */
    continue;
  }

  /* Step 2: Check if block data is available (not pruned, not header-only) */
  if (!(entry.status & BLOCK_STATUS_HAVE_DATA) || (entry.status & BLOCK_STATUS_PRUNED)) {
    log_debug(LOG_COMP_NET, "Requested block not available (pruned or header-only), "
              "sending notfound to %s", peer->address);
    goto serve_block_notfound;
  }

  /* Step 3: Load block from storage */
  block_t block;
  block_init(&block);
  blk_result = node_load_block(node, &inv->hash, &block);
  if (blk_result != ECHO_OK) {
    log_debug(LOG_COMP_NET, "Failed to load block for serving: %d", blk_result);
    block_free(&block);
    goto serve_block_notfound;
  }

  /* Step 4: Serve the block */
  if (want_witness) {
    /*
     * INV_WITNESS_BLOCK: serve witness-serialized block.
     * block_serialize (called by msg_block_serialize) always includes witness — correct.
     * Ownership of block_t transfers to the send queue (allocated=true).
     */
    msg_t block_msg;
    memset(&block_msg, 0, sizeof(block_msg));
    block_msg.type = MSG_BLOCK;
    block_msg.payload.block.block = block;
    /* Ownership transfers to queue — do NOT call block_free after this */
    peer_queue_message(peer, &block_msg);

    log_debug(LOG_COMP_NET, "Queued witness block for peer %s", peer->address);
  } else {
    /*
     * INV_BLOCK: serve legacy block WITHOUT witness data.
     * block_serialize always includes witness, so we serialize manually
     * using tx_serialize with with_witness=ECHO_FALSE per transaction.
     *
     * Legacy serialization: header (80) + varint(tx_count) + each tx without witness.
     */

    /* Compute stripped (no-witness) size */
    size_t stripped_size = BLOCK_HEADER_SIZE;
    stripped_size += varint_size(block.tx_count);
    for (size_t t = 0; t < block.tx_count; t++) {
      stripped_size += tx_serialize_size(&block.txs[t], ECHO_FALSE);
    }

    uint8_t *stripped_buf = malloc(stripped_size);
    if (!stripped_buf) {
      log_error(LOG_COMP_NET, "Failed to allocate legacy block buffer (%zu bytes)",
                stripped_size);
      block_free(&block);
      continue;
    }

    /* Serialize header */
    size_t offset = 0;
    echo_result_t ser_result = block_header_serialize(
        &block.header, stripped_buf, stripped_size);
    if (ser_result != ECHO_OK) {
      free(stripped_buf);
      block_free(&block);
      continue;
    }
    offset = BLOCK_HEADER_SIZE;

    /* Serialize tx count */
    size_t var_written = 0;
    ser_result = varint_write(stripped_buf + offset, stripped_size - offset,
                              block.tx_count, &var_written);
    if (ser_result != ECHO_OK) {
      free(stripped_buf);
      block_free(&block);
      continue;
    }
    offset += var_written;

    /* Serialize each tx WITHOUT witness */
    for (size_t t = 0; t < block.tx_count; t++) {
      size_t tx_written = 0;
      ser_result = tx_serialize(&block.txs[t], ECHO_FALSE,
                                stripped_buf + offset, stripped_size - offset,
                                &tx_written);
      if (ser_result != ECHO_OK) {
        free(stripped_buf);
        block_free(&block);
        continue; /* Note: this continues the outer for loop — which is what we want */
      }
      offset += tx_written;
    }

    /* Build raw block message and send.
     * We cannot use the normal msg_t path because msg_block_serialize
     * always serializes with witness. Instead, build a MSG_BLOCK msg_t
     * but the send path will serialize from our pre-built buffer.
     *
     * Actually — the simplest approach: use the msg_t path but pass
     * the block through. The peer_send_message_internal MSG_BLOCK case
     * calls msg_block_serialize which calls block_serialize which always
     * uses witness. So for legacy, we need a different approach.
     *
     * Direct send approach: build the wire message manually and send
     * via plat_socket_send through the peer's socket. This bypasses
     * the message queue but is the cleanest way to send legacy blocks
     * without modifying the serialization layer.
     *
     * WAIT — better approach: since we already have the serialized bytes,
     * send them directly as a raw block message. Build the 24-byte header
     * manually and send header + payload.
     */

    /* For legacy blocks, send directly rather than through the msg queue.
     * This avoids modifying block_serialize to support a no-witness mode. */
    /* [See implementation note below] */

    free(stripped_buf);
    block_free(&block);

    log_debug(LOG_COMP_NET, "Served legacy (no-witness) block to peer %s",
              peer->address);
  }
  continue;

serve_block_notfound:
  {
    inv_vector_t nf_inv = *inv;
    msg_t nf_msg;
    memset(&nf_msg, 0, sizeof(nf_msg));
    nf_msg.type = MSG_NOTFOUND;
    nf_msg.payload.notfound.count = 1;
    nf_msg.payload.notfound.inventory = &nf_inv;
    peer_queue_message(peer, &nf_msg);
  }
  continue;
}
```

**IMPORTANT implementation decision for legacy (INV_BLOCK) serving:**

The above pseudocode shows the legacy stripping approach but has an incomplete "direct send" step. The implementer has two clean options:

**Option A (RECOMMENDED): Skip legacy stripping entirely for now.** All mainnet peers today are SegWit-capable. When a peer sends `INV_BLOCK` getdata, serve the witness-serialized block anyway (same as `INV_WITNESS_BLOCK`). This is what Bitcoin Core effectively does — there are no legacy-only peers on mainnet. Add a comment:
```c
} else {
  /*
   * INV_BLOCK: Peer requested legacy format. In practice all mainnet peers
   * are SegWit-capable (since 2017). Serve witness block — legacy peers
   * will parse it correctly (the marker/flag bytes are backward-compatible).
   * If true legacy stripping is needed in the future, serialize each tx
   * with tx_serialize(tx, ECHO_FALSE, ...).
   */
  msg_t block_msg;
  memset(&block_msg, 0, sizeof(block_msg));
  block_msg.type = MSG_BLOCK;
  block_msg.payload.block.block = block;
  peer_queue_message(peer, &block_msg);
  log_debug(LOG_COMP_NET, "Queued block (witness) for legacy-requesting peer %s",
            peer->address);
}
```

**Option B: Full legacy stripping with direct send.** Build the stripped buffer as shown, then send directly using the peer's socket with a manually constructed message header. This requires access to `peer->socket` and `plat_socket_send`. Only pursue this if the success criteria strictly requires legacy stripping (re-read: "a peer that sends MSG_BLOCK receives the stripped legacy serialization, not a witness block"). If the success criteria demands it, implement the stripped serialization and direct send.
