1. Create `rbf_validate_replacement()`. Signature:
```c
static echo_result_t rbf_validate_replacement(
    mempool_t *mp,
    const tx_t *replacement,
    satoshi_t replacement_fee,
    size_t replacement_vsize,
    mempool_accept_result_t *result)
```

The function performs these checks IN ORDER:

**Step A: Build eviction set** — Call `rbf_collect_eviction_set()`. If it returns error (Rule 5 violated), propagate the error.

**Step B: Rule 1 — Signaling check** — Every entry in the eviction set must signal RBF (directly or inherited). For each entry in `eviction_set`, call `entry_signals_rbf_inherited(mp, entry)`. If any returns false, set `result->reason = MEMPOOL_REJECT_CONFLICT` and return `ECHO_ERR_INVALID`.

**Step C: Rule 2 — No new unconfirmed inputs** — For each input of `replacement`, if `txid_table_lookup(mp, &replacement->inputs[i].prevout.txid)` returns non-NULL (unconfirmed parent), verify that parent is in the eviction set. If the parent is NOT in the eviction set, set `result->reason = MEMPOOL_REJECT_CONFLICT` and return `ECHO_ERR_INVALID`. (A replacement introducing new unconfirmed dependencies is forbidden.)

**Step D: Rule 3 — Absolute fee check** — Compute `total_evicted_fees = sum of eviction_set[i]->fee for all entries`. Check `replacement_fee >= total_evicted_fees`. If not, set `result->reason = MEMPOOL_REJECT_RBF_INSUFFICIENT_FEE` and return `ECHO_ERR_INVALID`.

**Step E: Rule 4 — Fee rate increment** — Compute `required_fee = total_evicted_fees + (MEMPOOL_RBF_INCREMENT * replacement_vsize / 1000)`. The replacement must pay `replacement_fee >= required_fee`. This combines the "must pay for its own bandwidth" check with Rule 3. If not satisfied, set `result->reason = MEMPOOL_REJECT_RBF_INSUFFICIENT_FEE` and return `ECHO_ERR_INVALID`. Note: Rule 4 as implemented by Bitcoin Core adds the incremental relay fee to the total evicted fees, so this is a stricter check than Rule 3 alone.

**Step F: Atomic eviction** — All rules passed. Collect the direct conflict txids into a separate array BEFORE calling mempool_remove (since remove modifies the spent table). Then call `mempool_remove(mp, &conflict_txid)` for each direct conflict. `mempool_remove` handles recursive descendant removal.

**Step G: Return ECHO_OK** — The replacement will be inserted by the normal path in mempool_add that follows the `if (has_conflict)` block.
