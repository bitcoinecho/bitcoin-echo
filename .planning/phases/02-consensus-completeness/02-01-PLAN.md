<objective>
Fix OP_CHECKSIGADD BIP-342 unknown key type handling and validate with Tapscript test vectors.

Purpose: The current Tapscript executor rejects non-32-byte pubkeys with SCRIPT_ERR_WITNESS_PUBKEYTYPE, which violates BIP-342's upgrade rule. Unknown key types (length != 0 and != 32) must succeed without cryptographic verification. This same bug may affect OP_CHECKSIG/OP_CHECKSIGVERIFY in Tapscript context. Fixing this enables the node to correctly validate all Taproot multisig transactions on mainnet.

Output: Corrected script.c with BIP-342-compliant key type dispatch, and a new test_tapscript.c test suite validating OP_CHECKSIGADD with 32-byte keys, unknown key types, empty keys, and OP_SUCCESS opcodes.
</objective>
