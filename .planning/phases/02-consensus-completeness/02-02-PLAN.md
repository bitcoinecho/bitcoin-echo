<objective>
Add prev_chainwork to block_delta_t and wire full UTXO rollback in chaser_confirm_reorganize.

Purpose: Chain reorganizations currently have a TODO stub that skips UTXO rollback and leaves chainwork stale. Without this fix, any mainnet reorg leaves orphaned UTXOs in the UTXO set and incorrect accumulated work at the tip — both silent consensus failures. CONS-04 (prev_chainwork field) is a prerequisite for CONS-02 (rollback wiring) because chainstate_revert_block cannot restore chainwork without knowing the previous value.

Output: Extended block_delta_t with prev_chainwork field, save/restore logic in chainstate apply/revert, a new chainstate_get_delta accessor, and the complete rollback loop in chaser_confirm_reorganize that replaces the TODO stub.
</objective>

       /* Roll back to fork point — undo UTXO changes for each block */
       uint32_t old_height = chaser->confirmed_height;
       for (uint32_t h = old_height; h > fork_point; h--) {
           const block_delta_t *delta = chainstate_get_delta(chaser->chainstate, h);
           if (delta == NULL) {
               log_error(LOG_COMP_CONS, "Missing delta at height %u during reorg", h);
               /* Cannot proceed — delta was pruned or never stored */
               return ECHO_ERR_NOT_FOUND;

               log_error(LOG_COMP_CONS, "Failed to revert block at height %u", h);
